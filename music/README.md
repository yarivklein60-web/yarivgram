# Yarivify

נגן מוזיקה בסגנון Spotify, בעברית (RTL), שרץ כולו בדפדפן.

**Stack:** React 18 · Vite · Tailwind CSS · React Router · lucide-react

## הרצה

```bash
cd music
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ — אפשר להעלות לכל אחסון סטטי
```

## מה יש

- **ספרייה** — העלאת קובצי MP3/M4A/WAV/OGG/FLAC מהמכשיר (כפתור או גרירה). שם בפורמט `אמן - שם שיר.mp3` מתפרק אוטומטית.
- **פלייליסטים** — יצירה, שינוי שם (לחיצה על הכותרת), הוספה/הסרה של שירים, מחיקה.
- **שירים שאהבתי** — סימון בלב.
- **חיפוש** — לפי שם, אמן ואלבום, עם עיון לפי אמנים/אלבומים.
- **נגן** — ניגון/השהיה, הבא/הקודם, ערבוב, חזרה (רשימה/שיר), פס התקדמות, עוצמה והשתקה, "הוספה לתור".
- **מובייל** — ניווט תחתון, מיני־נגן ומסך "מתנגן עכשיו".
- מקשי מדיה ומסך נעילה (Media Session API), רווח = ניגון/השהיה.

## איך זה בנוי

```
src/
  lib/db.js        IndexedDB — השירים (כולל קובץ השמע) והפלייליסטים נשמרים בדפדפן
  lib/library.jsx  מצב הספרייה: שירים, פלייליסטים, לייקים, העלאה
  lib/player.jsx   מנוע הנגן: תור, ערבוב, חזרה, Media Session
  lib/synth.js     6 שירי דוגמה שמסונתזים בדפדפן (Web Audio) בהפעלה הראשונה — בלי קבצים מוגנים בזכויות יוצרים
  components/      Sidebar, PlayerBar, TrackList, TrackMenu, Cover…
  pages/           Home, Search, LibraryPage, Playlist
```

הנתונים נשמרים מקומית בכל דפדפן בנפרד — אין שרת ואין סנכרון בין מכשירים.
